O que é CSS

Uma regra CSS é um conjunto de instruções usado para definir o estilo (aparência visual) de elementos HTML em uma página. Ela fala para o navegador
quais elementos devem seram alterados (seletor) e como eles devem ser exibidos (são as propriedades e valores) Cada regra do CSS será formadobr
por um seletor e um bloco de declarações.

Exemplo da estrutura:

seletor {

    propriedade; valor
}

  • Seletor: vai referenciar qual elemento do HTML será estilizado.
  • Propriedade: Vai definir qual aspecto visual será alterado(como tamanho, cor, fonte, posição, etc).
  • Valor: É as especificação de como essa propriedade será aplicada.

Exemplo prático:

body{

    background-color; blue;
    color: white;
}

Resultado:

  • body (Seletor): está referenciando o seletor body que será estilizado.
  • (Propriedades) que defini os aspectos visuais que seram alterados:
    • background-color
    • color:
  • (Valores): as especificações para suas propriedades correspondentes
    • antiquewhite;
    • gray
  • (Mundança)
    • Mudança na cor de fundo do site
    • Mundaça na cor do texto para cinza
