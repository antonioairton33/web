O que é JavaScript?

1 - Motivação para criação:

O JavaScript foi criado em 1995 para consertar a defict de interatividade das páginas web, que na época eram totalmente estáticas. Essa ideia tinha como objetivo permitir que o navegador reagisse a ações do usuário, validasse formulários e atualizar partes da página sem precisar recarregar tudo. Pensando nisso a Netscape pediu ao desenvolvedor Brendan Eich que criasse uma linguagem rápida, simples e integrada ao navegador. Assim surgiu o JavaScript, com o objetivo principal de tornar a web mais dinâmica e interativa.

2 - Diferença entre execução do navegador e no servidor:

Execução no navegador:

  • O código roda no computador do usuário, dentro do navegador (Chrome, Edge, etc.).
  • Geralmente usa JavaScript.
  • Serve para interação da página, como animações, validação de formulários, menus, efeitos.
  • Não acessa diretamente dados sensíveis do servidor.

Execução no servidor:

  • O código roda no servidor, antes da página chegar ao usuário.
  • Pode usar várias linguagens: Node.js (JS no servidor), PHP, Python, Java, etc.
  • Serve para processar dados, acessar banco de dados, autenticação, regras de negócio.
  • Envia para o navegador apenas o resultado.

A execução no navegador acontece diretamente no computador do usuário e é usada para controlar a interação e o comportamento da página. Já a execução no servidor ocorre antes da página chegar ao usuário e é responsável por processar dados, acessar bancos de dados e aplicar regras da aplicação. Em resumo, o navegador lida com a parte visual e interativa, enquanto o servidor cuida da lógica e dos dados.

3 - Conceito de sandbox no navegador:

Sandbox no navegador é um mecanismo de segurança que isola o código JavaScript, impedindo que ele acesse diretamente o sistema do usuário ou informações sensíveis. Ele roda em um ambiente limitado, com permissões controladas, para evitar que páginas maliciosas executem ações perigosas. Em resumo, o sandbox protege o usuário mantendo o código da web separado do computador real.

4 - Explicação de obejtos globais como document, console e alert:

Objetos globais no JavaScript são recursos que o navegador já oferece automaticamente e que podem ser usados em qualquer parte do código. Eles servem para interagir com a página, mostrar mensagens ou acessar funções internas do navegador.

  • document: representa o documento HTML carregado. É por meio dele que o JavaScript consegue acessar e alterar elementos da página, como textos, botões, imagens e estilos.
  • console: é usado para exibir mensagens de teste ou depuração no console do navegador. Serve principalmente para desenvolvedores verificarem valores e identificarem erros.
  • alert: mostra uma janela simples com uma mensagem para o usuário. É útil para avisos rápidos, embora seja pouco usado em interfaces modernas.

O document conecta o JavaScript ao HTML, o console ajuda o desenvolvedor a fazer testes, e o alert exibe mensagens diretamente para o usuário.
