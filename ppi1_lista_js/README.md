💡 Descrição do Projeto

Este repositório contém as atividades da Lista de JavaScript, abordando fundamentos da linguagem, eventos, DOM, cálculos, armazenamento e canvas.

🗂️ Estrutura de Arquivos
Arquivo	Descrição
css/    Arquivos css utilizados.
imgs/	Imagens usadas no exercício de IMC.
js/     Arquivos js utilizados.
1.html	Introdução ao JavaScript: conceito, sandbox, objetos globais, hora atual.
2.html	Tipos de variáveis, operadores e typeof.
3.html	Cálculo de IMC com if/switch e imagens.
4.html	Sorteio de números com intervalo e histórico.
5.html	Números primos em um intervalo.
6.html	Verificador de palíndromos.
7.html	Mudança de cor ao clicar.
8.html	Mudança de cores com tecla espaço.
9.html	Calculadora aritmética.
10.html	Eventos de JS: click, keydown, focus, blur, mouseover, change.
11.html	Salvando nome no localStorage.
12.html	Desenho no canvas (retângulo, círculo e texto).
index.html Pagina inicial contnedo os links das questões.
README.md	Documento explicativo do projeto.
