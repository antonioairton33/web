## 💡 Descrição do Projeto
Este repositório contém as atividades da **Lista 1**, abordando os **fundamentos da Web, HTML e CSS**.  
O objetivo foi praticar a criação de páginas HTML estruturadas, formulários e estilização com CSS externo.


## 🗂️ Estrutura de Arquivos

| Arquivo | Descrição |
|----------|------------|
| **1.html** | Estrutura básica HTML e diferença entre Internet e Web. |
| **2_http.html** | Explicação sobre o protocolo HTTP com exemplos ilustrados. |
| **3_tabela_uf.html** | Tabela de estados e capitais, agrupadas por região. |
| **4_curriculo.html** | Currículo fictício com seções, tabela de horários e links. |
| **4_contato.html** | Página de contato com formulário validado via HTML. |
| **5_links.html** | Página contendos os links das atividades |
| **6_github.html** | Págin contendo o link do meu github onde fica localizado o repositório |
| **style.css** | Arquivo de estilos aplicado a todas as páginas. |
| **README.md** | Documento explicativo sobre o projeto. |
