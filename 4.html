Formularios

o HTML possui a tag form que possibilita submissão de dados informados pelo dentro do fomúlario. A tag <form> possui além dos atributos globais e também atributo action="url", utilizado para definir o destino dos dados submetidos. Exemplo: 

            <form action="url">
                <input type="text" name="variavelA">
            ...
            </form>

Table

A tag table é utilizada para definição de tabela no HTML, internamente em uma tabela podemos criar linhas "rows" utilizando a tag <tr> e celulas dentro das linhas utilziando a tag <td> exemplo: 

        <table>
            <tr>
                <td> Celula 1x1 </td> Celula 1x2 </td>
            </tr>
            <tr>
                <td> Celula 2x1 </td> Celula 2x2 </td>
            </table>
        </table>
O código anterior define a tabela abaixo
Celula 1x1 Celular 1x2
Celular 2x1 Celular 2x2
